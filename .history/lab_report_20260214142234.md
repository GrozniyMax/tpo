## Часть 1. Модульное тестирование разложения функции в степенной ряд

### Описание реализации

Функция `myArcsin(x)` реализует вычисление арксинуса через разложение в степенной ряд Тейлора. Для значений |x| ≥ 0.999999 используется тригонометрическое тождество для повышения точности вычислений:

```
arcsin(x) = π/2 - arcsin(√(1 - x²)) для x > 0
arcsin(x) = -π/2 + arcsin(√(1 - x²)) для x < 0
```

### Тестовое покрытие

1. **Граничные значения:**
   - Проверка arcsin(0) = 0
   - Проверка значений на границах области определения: ±1

2. **Точки внутри области определения:**
   - Тесты для стандартных углов: π/6, π/4, π/3
   - Использование CSV файлов с тестовыми данными для различных диапазонов

3. **Проверка выхода за область определения:**
   - Тесты для значений |x| > 1, которые должны возвращать NaN

4. **Проверка сходимости:**
   - Тестирование с различными значениями точности ε

## Часть 2. Модульное тестирование алгоритма красно-черного дерева

### Описание реализации

Реализовано полное красно-черное дерево с операциями:
- Вставка элементов с автоматической ребалансировкой
- Поиск элементов
- Удаление элементов с восстановлением свойств
- Обход дерева в порядке возрастания

### Характерные точки алгоритма

1. **Вставка узлов:**
   - Случай 1: Дядя узла красный (перекрашивание)
   - Случай 2: Узел является правым потомком (левый поворот)
   - Случай 3: Узел является левым потомком (правый поворот)

2. **Удаление узлов:**
   - Случай 1: Брат узла красный (перекрашивание и поворот)
   - Случай 2: Оба потомка брата черные (перекрашивание)
   - Случай 3-4: Один из потомков брата красный (перекрашивание и поворот)

### Тестовое покрытие

1. **Базовые операции:**
   - Проверка вставки нескольких элементов
   - Проверка поиска существующих и несуществующих элементов
   - Проверка удаления элементов

2. **Ребалансировка:**
   - Тесты для левых и правых поворотов
   - Тесты для изменения цвета узлов
   - Тесты для сложных сценариев с множественными ребалансировками

3. **Последовательность попадания в характерные точки:**
   - При вставке узлов 1, 2, 3 происходит левый поворот
   - При вставке узлов 3, 2, 1 происходит правый поворот
   - При вставке узлов 2, 1, 3 происходит изменение цвета
   - При вставке узлов 3, 1, 2 происходит лево-правый поворот
   - При вставке узлов 1, 3, 2 происходит право-левый поворот

### Результаты тестирования

Все тесты прошли успешно, что подтверждает корректную реализацию алгоритма красно-черного дерева и его операций ребалансировки.
