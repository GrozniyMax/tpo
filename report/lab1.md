## Часть 1. Модульное тестирование разложения функции в степенной ряд

### Описание реализации

Функция `myArcsin(x)` реализует вычисление арксинуса через разложение в степенной ряд Тейлора. Для значений |x| ≥ 0.999999 используется тригонометрическое тождество для повышения точности вычислений:

```
arcsin(x) = π/2 * arcsin(√(1 * x²)) для x > 0
arcsin(x) = -π/2 + arcsin(√(1 * x²)) для x < 0
```

### Тестовое покрытие

1. **Красивые точки:**
   * ± 1
   * ± 0.5 (π/6)
   * ± 0.707106781 (π/4)
   * ± 0.866025404 (π/3)
   * ± 1 (π/2)

2. **Проверка в рамках ОДЗ:**
   * Тесты для значений |x| <= 1

3. **Проверка выхода за область определения:**
   * Тесты для значений |x| > 1, которые должны возвращать NaN

## Часть 3. Доменная модель

>Минуту спустя последняя планета каталога исчезла, и они снова оказались в реальном мире. Они сидели в приемной, уставленной обитой плюшем мебелью, стеклянными столиками и наградами. Перед ними стоял высокий магратеянин.


### Классы доменной модели

1. **Species (Перечисление):**
   * MARSIAN (Марсианин)
   * HUMAN (Человек)

2. **Actor (Интерфейс):**
   * Методы для появления и ухода из места

3. **Person (Класс):**
   * Имя персонажа
   * Раса (Species)
   * Реализует интерфейс Actor

4. **Company (Класс):**
   * Название компании
   * Список людей
   * Реализует интерфейс Actor

5. **Place (Абстрактный класс):**
   * Абстрактные методы для отчета о входе/выходе
   * Множество находящихся внутри акторов

6. **Planet (Класс):**
   * Наследуется от Place
   * Представляет планету

7. **Room (Класс):**
   * Наследуется от Place
   * Представляет комнату с мебелью

8. **Furniture (Класс):**
   * Название мебели
   * Детали мебели

### Тестовое покрытие

1. **Тесты для Person:**
   * Проверка положения по умолчанию (Position.STANDING)
   * Проверка положения после посадки (Position.SITTING)
   * Проверка положения после вставания
   * Использование mockk для мокирования зависимостей

2. **Тесты для Chair:**
   * Посадка на стул
   * Попытка посадки когда кто-то уже сидит (IllegalStateException)
   * Вставание со стула
   * Попытка вставания другого человека (IllegalStateException)
   * Вставание с пустого стула (IllegalStateException)
   * Попытка вставания с пустого стула

3. **Тесты для Table:**
   * Добавление предметов на стол (Medal, Cup)
   * Проверка наличия предмета на столе (contains)
   * Попытка добавления одинакового предмета (IllegalStateException)
   * Попытка добавления предмета при переполнении (IllegalStateException)
   * Удаление предметов со стола (removeItem)
   * Попытка удаления предмета которого нет на столе (IllegalStateException)
   * Работа с пустым столом

4. **Тесты для Place (Planet, Room):**
   * Добавление нового человека (wentIn)
   * Добавление уже существующего человека (IllegalStateException)
   * Выход существующего человека (wentOut)
   * Выход несуществующего человека (IllegalStateException)
   * Тестирование методов интерфейса Actor (appear, leave)
   * Параметризованные тесты для Planet и Room
