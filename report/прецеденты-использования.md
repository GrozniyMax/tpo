# Прецеденты Использования (Use Cases)

### UC-01: Поиск жилья по городу

**Идентификатор:** UC-01  
**Наименование:** Поиск жилья по городу  
**Акторы:** Пользователь, Система  
**Триггер:** Пользователь открыл сайт "https://www.booking.com/"
**Результаты:** Просмотр предлагаемых вариантов жилья

**Предусловия:**

- Пользователь не авторизован
- Пользователь находиться на стартовой странице "https://www.booking.com/"

**Основной поток событий:**

| Шаг | Действующее лицо | Действие                          |
|-----|------------------|-----------------------------------|
| 2   | Пользователь     | Отклоняет авторизацию/регистрацию |
| 3   | Пользователь     | Вводит город в поле поиска        |
| 4   | Система          | Отображает подсказки для города   |
| 5   | Пользователь     | Выбирает первую подсказку         |
| 6   | Пользователь     | Нажимает на поле выбора дат       |
| 7   | Пользователь     | Выбирает даты поездки             |
| 8   | Пользователь     | Нажимает на кнопку выбора гостей  |
| 9   | Пользователь     | Выбирает количество гостей        |
| 10  | Пользователь     | Нажимает кнопку поиска            |
| 11  | Система          | Отображает подходящие варианты    |

**Постусловия:** Пользователь находится на странице результатов поиска жилья
